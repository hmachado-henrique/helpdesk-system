# HelpDesk System

## Objetivo

Desenvolver uma aplicação web para gerenciamento de chamados de suporte técnico, permitindo registrar incidentes, acompanhar seu andamento e organizar os atendimentos.

## Escopo da primeira versão

- Cadastrar chamados com título e descrição.
- Definir categoria e prioridade.
- Listar os chamados cadastrados.
- Alterar o status de um chamado.
- Editar e excluir chamados.
- Filtrar chamados por status e prioridade.

## Regras de negócio

- Todo chamado deve possuir um título e uma descrição.
- Todo chamado deve ter uma prioridade.
- Todo chamado deve possuir um status.
- Um chamado resolvido deve continuar disponível para consulta.
- Os dados devem ser validados antes de serem salvos.

## Tecnologias planejadas

- CSS
- JavaScript
- Git e GitHub

- Node.js e Express
- TypeScript
- React

As tecnologias serão introduzidas progressivamente, conforme a evolução do projeto e dos estudos.
